# 📝 To‑Do List

A simple, responsive, and intuitive web app for managing daily tasks. Built with plain **HTML**, **CSS**, and **JavaScript**, featuring local storage for persistence and a clean user interface.

---

## 🚀 Features

- ➕ **Add tasks** with description and due date  
- ✅ **Mark tasks** as completed or pending  
- 🗑️ **Delete tasks** with a confirmation prompt  
- 🔍 **Search/filter tasks** by keywords  
- 📅 View tasks by: `My Day`, `Current Week`, `Current Month`, or `All Tasks`  
- 👤 **Profile setup** (name & email stored in localStorage)  
- 🛠️ **Auto-sorting** by due date (ascending)  
- 📱 Fully **responsive** design for mobile and desktop
